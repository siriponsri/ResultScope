# ResultScope demo script (target: 170–180 seconds)

This is a recording plan, not evidence that a video was recorded.

1. **0:00–0:20 — purpose.** Open the local home. Say that ResultScope reads
   laboratory values, keeps the report's own units/ranges, and does not
   diagnose or prescribe.
2. **0:20–0:45 — first action.** Click a Thai CBC example and point out the
   single question field and the lab-only boundary.
3. **0:45–1:15 — deterministic layer.** Show the extracted value cards, low/
   high/within/unknown state, and the supplied report range. Open the rule
   disclosure.
4. **1:15–1:35 — evidence.** In an evidence-enabled local run, open source
   metadata and show organization, page, URL, license, and the separate public
   reference class. Do not call it business approval.
5. **1:35–1:55 — image review.** Upload a synthetic fixture, correct one value,
   and confirm it. State that live Vision/OCR is not part of this evidence.
6. **1:55–2:15 — safety/recovery.** Submit an unrelated question to show the
   local refusal, then show retry/reset and the mobile layout if time permits.

If the provider or Vision key is absent, use the mocked/local evidence labels
on screen and say so plainly. Do not record real patient data, `.env` values,
or an unverified live claim.
