# Product overview

ResultScope 3 is an LLM-first health-check business application: public discovery, free-text customer chat, confirmed report context, package previews, bookings, sandbox payments, web staff takeover and a LINE worker. /app is the customer workspace, /staff the service desk and /lab the retained v2 educational workspace. See ../../PRODUCT.md and ../business-v3/01_REQUIREMENTS.md for scope and ../business-v3/VERIFICATION.md for measured limits.
