# Roadmap

Implemented in v3: customer accounts and encrypted history, report confirmation and selected comparisons, current package catalog, explicit booking confirmation, staff inbox/takeover, organization quotations, center receipts and Stripe test adapters, and durable LINE jobs/linking. Medical retrieval uses 58 local verified-source records with an optional LightRAG adapter. The LLM owns conversational planning and prose; transaction authorization remains in code.

Next: owner-authorized real-model/OCR/guard acceptance, hosted PostgreSQL and Redis verification, signed LINE/Stripe integration runs, real map embed and measured semantic retrieval. These are configuration/acceptance gates, not completed live results.

Production work: email verification and recovery, account erasure and retention automation, clinical-role separation, independent security/clinical review, load tests and merchant onboarding. Speech and broader assistive memory remain future options. The 2035 research scenario is in ../research/CHATBOT_2035.md.
