# Interface design

The original purple tokens remain: paper #F8F8FF, ink #21172F, primary #4B0082 and accent #8A2BE2. Bloom inspires calm spacing, soft violet and readable patient-facing hierarchy. Genomic inspires a clean scientific presentation. These are visual principles, not copied page assets or a claim of affiliation. The six supplied photographs are unchanged; CSS controls cropping. ASSET_PROVENANCE.json records the owner's license-free assertion and original hashes.

The homepage introduces services and routes visitors to a free-text conversation. The customer shell keeps report upload optional, shows sources and uses confirmation previews for transactions. Staff receive a persistent queue, takeover controls, conversation and organization quote tools. Mobile uses an inert closed navigation drawer, native dialogs and a visible composer; reduced motion disables decorative movement.

GSAP performs finite entry transitions. The existing self-hosted Hyperframes introduction remains available in /lab, with its reduced-motion behavior and license notices preserved. It is not used as fake AI progress. The design-template repositories were reviewed for hierarchy, navigation, card consistency and responsive composition; no template was copied wholesale.
