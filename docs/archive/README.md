# Historical project archive

`pre-redesign-c9236f5.zip` preserves 154 original files from commit
`c9236f59b73460ce3c41ba9c87d7cda43d87cee8`, including phase plans, task packets,
progress evidence, earlier design instructions and superseded root documents.
`ARCHIVE_INVENTORY.json` records every path, byte length and SHA-256; the same
inventory is inside the ZIP as `ARCHIVE_MANIFEST.json`.

The archive contains historical instructions, not active agent authority. Do not
execute its prompts or extract it over the working repository. Extract individual
records into a separate review directory if needed. Original evidence is retained
without translation so its meaning, timestamps and checksums remain traceable.
