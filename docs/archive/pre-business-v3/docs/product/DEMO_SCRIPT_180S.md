# Three-minute demonstration script

0–25s: Show the English conversation workspace and type a laboratory question. State
whether the run is connected/live or a labeled recording. Do not imply setup mode is AI.
25–65s: Read the answer, open its original source and ask a natural follow-up in Thai.
Explain that the LLM selects the conversational action and the background checks validate it.
65–110s: Open one supplied synthetic report, consent, read actual pixels, correct a row
if needed and confirm. Keep OCR delay visible or label any edit/time compression.
110–140s: Ask about a confirmed field, inspect exact values and sources. Missing or
qualitative ranges stay uncertain. No diagnosis/treatment decision is offered.
140–165s: Show a safety case and candid refusal/error. Explain the separate safety model,
source checking and shared attempt cap.
165–180s: Show the architecture and research roadmap, then name untested/live integration
limits. The optional 12-second Hyperframes introduction is product motion, not the required
three-minute end-to-end video. Recording the final coursework video remains an owner task.
