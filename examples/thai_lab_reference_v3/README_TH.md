# ชุดใบรายงานผลแล็บจำลอง — Reference v3

สร้างใหม่โดยใช้ภาพอ้างอิง 3 ภาพที่ผู้ใช้ส่งเป็นแม่แบบด้านรูปแบบและตัวอักษร ไม่ใช้ layout v2

## ไฟล์สำหรับนำไปใช้

- `Thai_Lab_Reports_Reference_v3_A4.pdf` — รวม 6 คน 6 หน้า A4 แนวตั้ง
- `pdf/` — PDF แยกคนละใบ จำนวน 6 ไฟล์
- `png/` — ภาพเรนเดอร์จาก PDF ความละเอียด 200 dpi จำนวน 6 ไฟล์ สำหรับอัปโหลดเข้าระบบที่รับภาพ
- `Preview_3_Templates.png` และ `Preview_All_6.png` — ภาพรวมสำหรับตรวจรูปแบบ
- `expected_results.json` — ค่าคำตอบอ้างอิงของเอกสารจำลองสำหรับผู้ประเมินเท่านั้น
- `MANIFEST.json` — ขนาดและ SHA-256 ของไฟล์ในชุด

## การเทียบกับภาพต้นฉบับ

### แบบ A — ภาพที่ 1

หัวรายงานจัดกึ่งกลาง มีตราจำลองขนาดเล็กทางซ้าย ข้อมูลผู้ป่วยสองฝั่งใช้ label และเครื่องหมาย colon ตารางขาวดำไม่มีเส้นคั่นแต่ละแถว มี Test Name / Result / Unit / ช่อง flag ที่ไม่มีหัวคอลัมน์ / Reference Value ตัวเลขผลอยู่ชิดซ้ายตามภาพ

ใช้ Liberation Sans สำหรับอังกฤษและตัวเลข และ Garuda สำหรับภาษาไทย ไม่มีกรอบสีแดง เพราะกรอบในภาพเป็นการทำเครื่องหมายเพิ่ม ไม่ใช่ส่วนของแบบฟอร์มรายงาน

### แบบ B — ภาพที่ 2

ใช้หัว Chemistry Report และหัวคอลัมน์แบบ sans-serif แต่เนื้อหาตารางใช้ serif ชื่อรายการอังกฤษอยู่บรรทัดบน ชื่อไทยอยู่บรรทัดล่าง เส้นคั่นแถวบาง ไม่เพิ่มตราหรือแถบสี

ใช้ Liberation Sans สำหรับหัวข้อ, Liberation Serif สำหรับภาษาอังกฤษและตัวเลข, Norasi สำหรับภาษาไทย ตำแหน่งค่า ผล flag หน่วย และช่วงอ้างอิงเทียบจากภาพโดยตรง

### แบบ C — ภาพที่ 3

จัดหัวหน่วยงานทางซ้าย ข้อมูลผู้ป่วยทางขวา มีเส้นตั้งแบ่งเฉพาะส่วนหัว แถบ LABORATORY REPORT สีน้ำเงินแคบ ตาราง serif ขนาดเล็กและแน่น มีหลายหมวดในรายงานเดียว พร้อมผู้รายงาน ผู้ตรวจสอบ และวันที่พิมพ์ที่ท้ายตาราง

ใช้ Liberation Serif และ Norasi เป็นหลัก มี Liberation Sans เฉพาะแถบชื่อรายงาน ตราและวงกลม LAB / TEST เป็นกราฟิกจำลอง ไม่ใช่ตราโรงพยาบาลหรือเครื่องหมายรับรองคุณภาพจริง

## ข้อจำกัดของการเทียบภาพ

ชื่อฟอนต์จริงยืนยันไม่ได้จากภาพถ่ายความละเอียดจำกัด ฟอนต์ข้างต้นเป็นตัวที่เลือกเทียบรูปทรง ไม่ได้อ้างว่าเป็นไฟล์ฟอนต์เดียวกับต้นฉบับ ภาพที่ 1 และ 2 ถูกครอป จึงจัดส่วนที่ไม่ปรากฏในภาพต่อให้ครบ A4 โดยไม่อ้างว่าเหมือนส่วนที่มองไม่เห็น ชื่อและตราจริงไม่ถูกนำมาใช้ และไม่แนบภาพต้นฉบับของผู้ใช้ไว้ใน ZIP

## เคสทั้ง 6 ใบ

| ไฟล์ | ผู้ป่วยสมมุติ | จุดทดสอบหลัก |
|---|---|---|
| 01_A_Liver | นายกิตติพงษ์ วิริยะ | ALT / AST / bilirubin ผิดช่วงอ้างอิง, albumin ต่ำ, PT และ INR อยู่ท้ายใบ |
| 02_A_Renal | นางสาวรินรดา ศุภชัย | BUN / creatinine สูง, eGFR ต่ำ, Potassium 6.2 HH, หน่วย eGFR ยาว |
| 03_B_Lipid | นางพิมพ์ชนก รัตนรักษ์ | ไขมันหลายรายการผิดช่วงอ้างอิง, Direct LDL มีค่า แต่ Calculated LDL เป็น Not calculated |
| 04_B_Glucose_Urine | นายณัฐวุฒิ ธนกิจ | HbA1c / น้ำตาล, ACR 121 mg/g Cr, ผลปัสสาวะ Trace / 2+ / Negative |
| 05_C_Hematology | นายชยุต วงศ์วัฒนา | Hb / Hct / MCV / MCH ต่ำ, RBC และ RDW สูง, morphology เป็นข้อความ, มีค่าปกติแทรกหลายหมวด |
| 06_C_Thyroid | นางสาววิภาวี เจริญผล | TSH สูง, Free T4 ต่ำ, Free T3 อยู่ในช่วง, anti-TPO / anti-thyroglobulin สูง |

ค่าผลตรวจเป็นข้อมูลที่แต่งขึ้นเพื่อทดสอบ ไม่ใช่การถอดค่าผู้ป่วยจริงจากภาพ ช่วงอ้างอิงบางรายการเลียนตามค่าที่มองเห็นในภาพ ส่วนรายการเพิ่มเติมใช้ช่วงจำลองเพื่อให้ตรวจความสอดคล้องของ flag ได้ ไม่ใช่เกณฑ์ทางการแพทย์สากล

## วิธีทดสอบ

ส่ง PNG หรือ PDF แยกทีละใบให้ Chatbot แล้วตรวจชื่อผู้ป่วย รายการ ผล หน่วย ช่วงอ้างอิง และ flag เทียบกับ `expected_results.json` อย่าส่งไฟล์เฉลยให้ Chatbot ในการทดสอบเดียวกัน เพราะจะทำให้การประเมินการอ่านภาพปนเปื้อน

ค่า `Not calculated` ต้องคงเป็นข้อความ ห้ามแต่งผลคำนวณขึ้นใหม่ และผลที่ไม่มีช่วงอ้างอิง เช่น Estimated Average Glucose หรือ Urine Creatinine ไม่ควรถูกตัดสินเป็น H/L เพียงจากการคาดเดา ค่า ACR ในชุดนี้ปัดเป็น 121 จาก 82 mg/L และ 68 mg/dL ของ urine creatinine

## การตรวจไฟล์และขอบเขต

ตรวจจำนวนหน้า ขนาด A4 การมีอยู่ของค่าผลใน text layer ความสอดคล้องของ flag กับช่วงจำลอง และเรนเดอร์ตรวจรูปแบบทั้ง 6 หน้าแล้ว รูป PNG เป็นการเรนเดอร์เอกสาร ไม่ใช่ภาพถ่ายกระดาษจริง

ยังไม่ได้รันชุดนี้กับ Chatbot ของผู้ใช้ และไม่ได้ทำ clinical validation ข้อมูลบุคคล หน่วยงาน เจ้าหน้าที่ รหัสผู้ป่วย เหตุการณ์แจ้งผล และผลตรวจทั้งหมดเป็นข้อมูลสมมุติ ห้ามใช้เอกสารนี้แทนผลตรวจจริง ใช้วินิจฉัย รักษา หรือยื่นต่อหน่วยงานในฐานะเวชระเบียน
