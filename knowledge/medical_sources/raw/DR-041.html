Urinalysis

ห้องปฏิบัติการสาขาวิชาวักกะวิทยา ภาควิชาอายุรศาสตร์

1. การทดสอบ :

 

Urinalysis

2. ข้อบ่งชี้ในการส่งตรวจ (indication) :

 

Diagnosis and Management of renal diseases involving urinary system

3. การเตรียมผู้ป่วย ( patient preparation ) :

 

เตรียมผู้ป่วยแบบ aseptic technique

4. สิ่งส่งตรวจ ( specimen ) ปริมาณและภาชนะที่ใช้เก็บ ( collection medium ) :

 

ปัสสาวะที่ถ่ายแต่ละครั้งในเวลาใดก็ได้ ใส่ในภาชนะสำหรับเก็บปัสสาวะทั่วไป ที่แห้งสะอาด ปริมาตร 15 - 20 มิลลิลิตร

5. การส่งสิ่งส่งตรวจและข้อควรระวัง ( handling ) :

 

5.1 การเก็บปัสสาวะต้องเก็บอย่างสะอาด (Clean catch) ถูกวิธีและเก็บเฉพาะช่วงกลางของปัสสาวะ (Midstream urine ) โดยให้ผู้ป่วยทำความสะอาดบริเวณอวัยวะสืบพันธุ์ภายนอก แล้วถ่ายปัสสาวะในช่วงแรกทิ้ง เก็บปัสสาวะช่วงกลางใส่ภาชนะ ส่วนปัสสาวะในช่วงสุดท้ายทิ้งไป

5.2 ควรส่งไปห้องปฏิบัติการสาขาวิชาวักกะวิทยา ตึกจุฑาธุช ชั้น 3 ภายในเวลา 1 ชั่วโมง หลังจากเก็บสิ่งส่งตรวจ

 

6. วันและเวลาทำการตรวจ (testing schedule) :

 

·        รับสิ่งส่งตรวจ ทุกวันราชการ เวลา 8.00 - 15.00 น.

·        ตรวจวิเคราะห์ ทุกวันราชการ เวลา 8.30 - 15.30 น.

7. การประกันเวลาการทดสอบ ( TAT ) :

 

ภายหลังจากอาจารย์แพทย์/แพทย์ประจำบ้านต่อยอด ของสาขาวิชาวักกะวิทยา มาดูตะกอนปัสสาวะเรียบร้อยแล้ว

8. การรายงานผล :

 

·        ค่าอ้างอิง (Reference value)

·        pH 4.6 – 8.0

·        sp.gr.  1.003 – 1.030

·        Albumin Negative

·        WBC 0 – 5 /HP

·        RBC  0 – 2 /HP

·        Squamous Epithelium Few / HP

·        (การรายงานผลต่อ)

·        Trasitional Epithelium Few / HP

·        Renal tubular Epithelium Few / HP

·        Cast  0 – 2 hyaline cast / LP

·        Crystal Negative

·        Bacteria Negative

·        Yeast Negative

·        แพทย์ประจำสาขาวิชาวักกะวิทยา ผู้ส่งตรวจเป็นผู้มาดู Urine sediment เอง โดยเจ้าหน้าที่ห้องปฏิบัติการสาขาวิชาวักกะวิทยา เป็นผู้นำผล Urine sediment มาลงในระบบ HCLAB และทางหอผู้ป่วยสามารถเปิดดูผลและพิมพ์ผลการวิเคราะห์ได้ทางระบบ E-Clair

9. ค่าตรวจ (charge) :

 

80 บาท หรืออาจเปลี่ยนแปลงตามประกาศของคณะฯ

10. วิธีการวิเคราะห์ (methodology) :

 

10.1 การตรวจโปรตีน (Qualitative) โดย Reagent Strip for Urinalysis

10.2 การวัดความถ่วงจำเพาะของปัสสาวะด้วย Refractometer

10.3 การตรวจตะกอนปัสสาวะด้วยกล้องจุลทรรศน์

11. สิ่งรบกวนต่อการวิเคราะห์ ( interference ) :

 

การรับประทานวิตามินซีปริมาณมากอาจทำให้การแปลผลน้ำตาลในปัสสาวะต่ำกว่าปกติ

12. ระยะเวลาที่สามารถขอตรวจเพิ่มได้ (time limit for requesting additional test) :

 

ไม่มี

13. อื่น ๆ ( comment ) :
